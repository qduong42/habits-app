# All data is personal-only in v1 — shared household tasks are explicitly v2

Although the app supports multiple users (Huy + partner) and the predecessor task tracker was built around shared household tasks (`owner_id NULL` = shared), v1 scopes every entity — tasks, habits, dumps, XP — strictly per-user. Decided 2026-06-09 to keep the overnight AFK build small and the XP economy unambiguous (who earns XP for a shared chore is a real design question we deferred). When shared tasks arrive in v2, expect changes to task visibility, completion attribution, and possibly XP rules.
