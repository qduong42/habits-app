# v1.2 Night Shift Implementation Plan

> **For agentic workers:** Each worker is a FRESH `claude -p` session executing exactly ONE task. Steps use checkbox (`- [ ]`) syntax for tracking. The v1 plan's **"Rules for every worker"** (docs/superpowers/plans/2026-06-09-habits-app-v1.md, Rules 1–11) are binding, with branch **feat/v1.2-night** substituted everywhere. Decisions: `docs/superpowers/specs/2026-06-11-v1.2-night-design.md` (the spec — READ IT FIRST) + `new_features.md` (2026-06-11 00:25 entries) + `CONTEXT.md`. On any conflict: new_features.md > spec > this plan.

**Goal:** Ship Done History, Task Reminders, Change Password, and the 7 polish items from `current_issues.md`.

**Architecture:** Done History = read-only view module over existing tables (NO new event table). Reminders = two nullable columns on `tasks` + a per-minute scheduler scan + Edit-UI fields. Password = one settings endpoint + Profile section. All server modules follow the existing `<domain>/{routes,service}.ts` pattern; web follows the existing hook-per-domain + page pattern.

**Tech Stack:** Express 5 + Drizzle + Postgres, zod v4, vitest + supertest, React + Vite PWA, react-query. Verify gate: `npm run verify` from repo root.

**Standing rules (every task):** TDD — write failing tests first, then implement. `npm run verify` green before commit. One commit per task using the given message + Co-Authored-By trailer, push to `origin/feat/v1.2-night` after commit. Smoke tests: throwaway users only (NEVER huy/lea/sasi), clean up `user_achievements`. Never touch running containers, `.env*`, or master. If blocked, append the reason to `docs/superpowers/ralph/BLOCKED.md`, commit that, and exit.
