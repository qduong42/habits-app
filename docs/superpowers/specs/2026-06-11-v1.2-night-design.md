## 1. Done History (Today page)

Read-only merged timeline of every done-click, at the bottom of Today.

- **Server:** new module `server/src/history/{routes,service}.ts`, mounted at `/api/history` in `app.ts` behind existing auth. `GET /api/history?limit=` (default and hard cap 2000). One `UNION ALL` query scoped to the caller: `checkins ⋈ habits.name` (kind `checkin`) + `task_completions ⋈ tasks.name` (kind `completion`), ordered `createdAt` desc. Entry: `{ id, kind: 'checkin'|'completion', name, localDate, createdAt }`.
- **Web:** `web/src/hooks/useHistory.ts` mirroring `useInboxAll`'s lazy pattern (enabled-flag query, fetch on first expand). `Today.tsx` gains a collapsed **History** section at the very bottom, same UX as Dump History: date rows ("Jun 10 · 7 done", newest first) → tap to expand that day's rows `✅ Morning sunlight · 07:12` / `📦 Water plants · 09:30`. Group by the server's `localDate` (NOT browser-local). Read-only — no actions on rows.
- **Empty/error:** "Nothing completed yet" placeholder; query errors render inline in the section like Dump History does.
- **Accepted limitations (promotion triggers, do not "fix" tonight):** cascade deletes erase history of deleted items; renames rewrite old entries (live join).

## 2. Task Reminders (one-off Tasks)

A **Reminder** = optional `remindAt` timestamp on a one-off Task; one push notification when reached; the Task **never** leaves Today (snooze rejected).

- **Schema (migration):** `tasks.remind_at` timestamptz nullable, `tasks.reminded_at` timestamptz nullable.
- **API:** task create/update accept `remindAt: ISO | null` — **400 on recurring tasks** (`intervalHours` set). Updating `remindAt` clears `remindedAt`. Serializer returns both fields.
- **Scheduler:** alongside the existing node-schedule nudge job, a per-minute scan: `remind_at <= now() AND reminded_at IS NULL AND completed_at IS NULL` → web-push "🔔 <task name>" to the owner's subscription → stamp `reminded_at` **always**, even when the owner has no push subscription (a missed reminder for an unsubscribed user is accepted, same as nudges; never leave it unstamped — that would refire every minute). Push failure with 410: existing cleanup path applies.
- **Web:** in the task ⋯ Edit UI only (Triage untouched): date input + time input (time defaults 09:00), Clear button. Show a small 🔔 badge + date on task rows that have a pending reminder.

## 3. Change Password

- **API:** `POST /api/me/password {currentPassword, newPassword}` in the settings module. bcrypt-verify current → wrong = 401 `wrong_password`; zod: newPassword min 8. Updates `users.password_hash` → `{ok:true}`. Existing JWTs stay valid (accepted for tailnet-only v1).
- **Web:** Profile page "Change password" section: current + new password fields, Save, success confirmation, inline error on 401.
